# NFL Matchup Brief Agent

ITEC 590 capstone, Ethan Milner. Ask about an upcoming NFL game and get a short brief with every fact tagged by its source: [odds], [weather], [stats], or [news]. A matchup analysis tool, not a betting picks service.

- `agent.py`: the tools, the News Analyst sub-agent, and the agent loop
- `streamlit_app.py`: the web page

API keys are stored in the app's Secrets settings on Streamlit Community Cloud, never in this repo.
